## Variables de control y fuentes de datos contextuales

Variables socioeconómicas, geográficas y de seguridad usadas como controles en la regresión de demanda por colegios.

### Indicadores socioeconómicos
- **em2021_diccionario.ods**: diccionario de variables de la Encuesta Multipropósito 2021. Fuente: Secretaría Distrital de Planeación vía datos abiertos Bogotá. URL: https://datosabiertos.bogota.gov.co/dataset/encuesta-multiproposito-2021-sdp
- **em2021_variables_adicionales.csv**: indicadores de la Encuesta Multipropósito 2021 por UPZ (IPM, estrato, densidad). El archivo supera el límite de 25MB de GitHub y no se almacena en el repo. Descargar desde la misma URL anterior.

### Geográficos y de transporte
- **estaciones_transmilenio.geojson**: estaciones troncales de TransMilenio. Fuente: Transmilenio S.A. vía datos abiertos Bogotá.
- **paraderos_sitp.geojson**: paraderos SITP para controles de accesibilidad. Fuente: Transmilenio S.A. vía datos abiertos Bogotá.
- **parques_bogota.geojson**: parques del POT Bogotá D.C. Fuente: Secretaría Distrital de Planeación vía datos abiertos Bogotá.

### Seguridad
- **delitos_alto_impacto.geojson**: estadísticas de delitos de alto impacto por localidad. Fuente: Secretaría Distrital de Seguridad, Convivencia y Justicia vía datos abiertos Bogotá.
